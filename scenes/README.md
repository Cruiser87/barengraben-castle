# Optional scene backdrops

The game draws every scene itself. If you drop a picture into this folder with one of the names below, the game uses it as the full-screen backdrop for that place instead, with her bear standing in front. Anything without a picture keeps the drawn scene.

**How to add one:** make or find a wide 16:9 image (about 1600×900, .webp, .jpg or .png), name it exactly as listed (for example `macys.jpg`), put it in this `scenes` folder and commit. The game tries .webp, then .jpg, then .png.

**Prompt tip for an AI image tool:** start with the scene line below, then add: *cozy storybook illustration, rich detail, warm glowing light, eye-level view, wide 16:9, no people, no text or logos, leave open floor space in the front for a character to stand.* Only use pictures you're allowed to use.
