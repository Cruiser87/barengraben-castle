# Bärengraben Castle

A cozy bear game set in a Victorian town inspired by Bern, Switzerland.

Play it at **https://cruiser87.github.io/barengraben-castle/**

The whole game is the single `index.html` file. Progress is saved in the player's browser (`localStorage`), and the in-game **💾 Save Game → Download save file** button makes a `.json` backup that can be loaded on any computer.

To update the game, replace `index.html` and commit.

Optional: put backdrop pictures in the `scenes/` folder to replace the drawn backgrounds of stores, landmarks, museums and boats. See `scenes/README.md` for the file names.
